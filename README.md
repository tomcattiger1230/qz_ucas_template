# 泉州装备制造研究所论文模版

Style files are stored in _style_ folder.

研究生开题请参照*proposal.tex*，毕业论文请参照*thesis.tex*

## 福州大学开题报告模板

[fzu_proposal_template/](fzu_proposal_template/) 目录是福州大学专业学位研究生论文开题报告 LaTeX 空白模板，版式按福大开题报告 Word 模板（FZU Body / FZU H1~H3 样式）还原，填写说明见 [fzu_proposal_template/README.md](fzu_proposal_template/README.md)，编译效果可参考目录下的 示例输出-骨架编译结果.pdf。

编译需 XeLaTeX 引擎：进入 `fzu_proposal_template/` 后运行 `latexmk`（或 `./build.sh`，Windows 双击 `build.bat`）。
